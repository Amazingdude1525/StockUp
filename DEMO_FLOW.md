# Demo Flow

1. Choose **Customer**, add Coke, Maggi, Bread, Milk, Eggs, and Lay’s, then checkout.
2. Open **My orders** to show the persisted order code and live fulfilment stage.
3. Choose **Network Admin**, submit the prefilled verified access form, and open Orders.
4. Show the selected warehouse, deterministic allocation reason, indoor map, exact bins, and corridor route.
5. Choose **Worker**, submit the prefilled WH02 access form, and select the new task from the task queue.
6. Start picking. Enter a wrong barcode to demonstrate server rejection, then enter the expected barcode to commit the pick.
7. Use **Item not found** on the next item to show the alternate-bin reservation and recalculated route.
8. Return to Admin and inspect updated Inventory and the employee-attributed Movement ledger.
9. Open Intelligence to run a real simulated surge or execute a recommended inventory transfer.
